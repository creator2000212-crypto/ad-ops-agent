# 案例页模板

复制下面的结构，替换方括号内容。公开前先脱敏，并对每一项结果标明证据来源。首页只引用摘要和链接。

```markdown
# [任务名称]

> 历史时间：[日期与时区] · 平台与对象：[范围] · 来源：[文件/回执类型]

**任务是什么：**[一句话] · **交付了什么：**[可核对的产物或状态] · **人决定什么：**[仍需确认的选择] · **可以复用什么：**[条件化的检查或流程]

## 任务与输入

[业务目标、产品条件、已有方法、账户/素材范围；未知项单列。]

## 人的决定

[用户确认的目标、方法、预算和授权范围；尚待确认的内容。]

## Agent 的准备与操作

[按顺序列出方案、候选、配置、提交等动作；标明哪些只在离线示例中完成。]

## 交付与状态核对

| 对象 | 交付或操作 | 回执/读回 | 结论与待办 |
| --- | --- | --- | --- |
| [对象] | [内容] | [来源及时点] | [可确认的范围] |

## 证据能证明到哪

- 已确认：[有来源的事实]
- 尚未确认：[发布、审核、消耗、效果或其他待回读事项]
- 保留的冲突：[不同时间或来源不一致时逐项说明]

## 可复用的检查

[提炼条件化流程，不把此任务的投法、阈值或结果推广为通用规则。]
```

相关写法见 [首页展示规范](showcase-style.md)、[任务记录模板](../templates/task-record.zh-CN.md) 和 [已有脱敏案例](case-studies.zh-CN.md)。
