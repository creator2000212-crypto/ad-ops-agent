# 怎样搭建一个投放 Agent

[English](build-from-zero.md) · [看一轮工作示例](../demo/README.zh-CN.md)

这套 Agent 的目标是帮你整理素材、配置广告、汇总数据，让你把时间放在理解结果和决定下一步。

搭建时，按这一条线往下走：

**先接账户 → 了解业务 → 确定做法 → 处理每天工作 → 记住确认过的经验。**

## 1. 先接账户

**你提供：**准备使用的平台、账户，以及已有的连接方式。

**Agent 帮你：**检查能否读取、配置和核对这些账户，列出缺少的条件。

先接本次要用的账户，不必同时接齐 Meta、TikTok 和 Google。

## 2. 了解业务

**你提供：**产品、国家、投放目标、预算、目标人群，以及网站或 App 怎样赚钱。

**Agent 帮你：**整理已知信息，只追问影响当前任务的缺项；不知道的先保留未知。

这些信息掌握清楚后，再准备投放方案。

## 3. 确定做法

**你提供：**这次想解决的问题，以及已有的方法或偏好。

**Agent 帮你：**新手先看几个候选做法；资深投手可以带自己的方法，再一起确认怎么测、看什么、何时调整。

方案由你确认后采用，示例中的数字不直接套用到你的业务。

## 4. 处理每天工作

**你提供：**本轮素材、数据和允许操作的范围。

**Agent 帮你：**选出符合要求的素材、准备配置、整理数据，并把建议和依据放在一起供你审阅。

整批方案确认后才执行；执行后核对实际结果，把未完成项留下来。

## 5. 记住确认过的经验

**你提供：**哪些判断需要纠正，哪些做法希望以后继续使用。

**Agent 帮你：**整理成待确认的经验，写清适用产品和条件；你确认保存后，后续任务再复用。

新观察先作为候选。改方法要再次确认，不能把一次成功当成通用规则。

## 当前做到哪里

以上是搭建顺序和目标工作方式。当前仓库只能离线演示，数据是虚构示例；尚未接入真实广告账户，也不会自动学习。真实发布仍需完成接入与授权。
