# How to build an advertising agent

[简体中文](build-from-zero.zh-CN.md) · [See one working round](../demo/README.md)

This agent aims to organize assets, prepare ad settings and summarize data, leaving you more time to understand results and decide what to do next.

Build it in this order:

**Connect accounts → Understand the business → Agree on a method → Handle daily work → Retain confirmed experience.**

## 1. Connect accounts

**You provide:** the platforms and accounts you want to use, plus any existing connection.

**The agent helps:** check whether those accounts can be read, configured and checked afterward, and identify missing requirements.

Start with the accounts needed now. You do not need to connect Meta, TikTok and Google together.

## 2. Understand the business

**You provide:** the product, countries, goals, budget, audience and how the website or app earns revenue.

**The agent helps:** organize known information and ask only about gaps that affect the current task. Unknowns stay unknown.

Establish this context before preparing a campaign plan.

## 3. Agree on a method

**You provide:** the problem to solve and any existing methods or preferences.

**The agent helps:** offer candidates to newcomers or work from an experienced buyer's own method. Together, agree on what to test, what to measure and when to reconsider.

Adopt the plan after your confirmation. Example numbers are not defaults for your business.

## 4. Handle daily work

**You provide:** the current assets, data and permitted scope of work.

**The agent helps:** select assets that meet the requirements, prepare settings, organize data and present recommendations with their evidence for review.

Execute only after the batch is confirmed. Check the actual result afterward and retain unfinished items.

## 5. Retain confirmed experience

**You provide:** corrections and practices you want to keep using.

**The agent helps:** turn these into proposed lessons, identifying the relevant product and conditions. Reuse them in later tasks after you confirm they should be saved.

New observations start as candidates. Changes need confirmation; one success does not establish a general rule.

## What works today

This is the build order and intended workflow. The repository currently runs offline demonstrations with fictional data. It has no live ad-account connection or automatic learning. Real publishing still requires integration and authorization.
