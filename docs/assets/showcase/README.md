# Showcase image assets

The 32 PNG files here were decoded from the user-provided local HTML visual preview dated 2026-09-25. The preview supplied four image kinds (`hero`, `meta`, `tiktok`, `workflow`) in Chinese and English, light and dark, wide and narrow versions. The original editable SVG source files mentioned in the proposal were not attached and are not represented here.

Naming: `<kind>.<language>.<theme>.<width>.png`, where language is `zh-CN` or `en`, theme is `light` or `dark`, and width is `wide` or `narrow`.

The README uses these files with `<picture>`. When changing a graphic, update all relevant versions and keep the accompanying Markdown text, alt text, evidence claims and language pair aligned. See [the style guide](../../showcase-style.md).
