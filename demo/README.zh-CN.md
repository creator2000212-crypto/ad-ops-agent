# 用一个例子看懂这个 Agent

[English](README.md) · [返回首页](../README.zh-CN.md)

**你定目标和投放方法，Agent 帮你检查广告、整理调整建议，把需要你决定的事情列出来。**

下面用虚构数据演示一次检查，不会修改真实广告账户。

## 你提出需求

> 帮我检查昨天的投放，看看哪些需要调整。

## Agent 做三件事

**1. 找出值得关注的广告。**

例如，一组广告没有转化，但展示次数还少，先继续观察；另一组已达到你设定的止损条件，列为暂停建议。使用哪套标准，由你选择。

**2. 列出具体建议，检查是否还需要改。**

例如，建议把 a1 的预算从 10 调到 20。已经暂停的广告不重复安排暂停；预算发生变化或资料缺失的，单独列出来等你判断。

**3. 整理结果，告诉你还剩什么问题。**

本例最后需要跟进三件事：

- **a9：**预算已经变化，先确认原因。
- **b1：**缺少当前状态，先补充数据。
- **a6：**目标预算是 40，结果文件里仍是 20，需要继续核对。

你看到的是“建议怎么改、为什么、还有什么没解决”，再决定下一步。

## 确认后会自动操作吗？

目标流程是：**Agent 出方案 → 你确认 → Agent 在授权范围内操作 → 检查结果。**

当前 demo 只用文件演示建议和核对，没有连接真实账户，也没有实际执行调整。

## 自己看一次

直接打开[本例的完整报告](expected/report.md)，或在项目目录运行：

```bash
python3 demo/run_demo.py
```
