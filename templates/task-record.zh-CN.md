# 投放任务记录模板

[English](task-record.md) · [使用方法](../docs/workflow.zh-CN.md)

**谁来填：**默认由 Agent 根据本次对话、已提供资料和实际工具结果整理，保存到用户为本任务允许使用的私有位置。用户核对任务范围、方案、预算和决定，不必手工填完整份表。

**怎样用：**从[第一次使用](../docs/first-check.zh-CN.md)或[日常任务工作流](../docs/workflow.zh-CN.md)进入。只保留本次需要的栏目：只读分析通常填写“任务与依据”和“交接”，创建/修改对象时再填写方案、授权和读回。未涉及项写“不适用”，所需证据缺失写“未知”，不以补齐表格为理由推测。

此模板是宿主工作记录，不会自动调用工具，不是 Python 输入格式。不要保存密码、令牌或密钥；业务资料与账户标识不得进入公开仓库。用户另行要求保存可复用经验时，再记录其保存范围与授权。
