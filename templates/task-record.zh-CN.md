# 投放任务记录模板

[English](task-record.md) · [使用方法](../docs/workflow.zh-CN.md)

复制到用户自己的私有目录后填写。此模板是宿主工作记录，不会自动调用工具，不是 Python 输入格式。方括号内容需用真实来源补齐；没有证据就写未知。不要在这里保存密码、令牌或密钥。

## 任务与依据

- 任务 / 计划版本：[本地编号与版本]
- 用户要解决的问题：[原意、来源与时间]
- 平台 / 账户 / 产品范围：[本次范围]
- 连接及所需能力：[工具与已检查能力、时间、缺口]
- 日期 / 时区 / 币种 / 数据截至：[明确口径]
- 当前方法：[版本、适用范围、用户采用依据]
- 上一轮相关待办：[无 / 待回验记录]
- 已知事实 / 假设 / 未知 / 冲突：[分别记录]
